# Visual source assets

`brand.svg` is the original 1280×640 social preview. The geometric cell is a symbolic brand mark, explicitly labelled as illustrative. `architecture.svg` documents software boundaries. `workflow.svg` documents scientific data flow, partitioning, calibration, acquisition, reference reveals and evaluation. Every SVG retains editable text and geometry; matching PNGs provide convenient previews.

`lab.png` and `lab-revealed.png` are preserved screenshots from the earlier release; their creation and use are recorded in the launch film's provenance and verification files. `lab-workbench.jpg` is a 1440 × 1000 native-browser capture of the updated local workbench, captured 2026-11-16 from the public base `b6da6866c77789fdb92fc6d880ec8f28a1897efb` plus the local portable-session and UI candidate. It shows PaMnF₆ selected, with one previously revealed ErI₄ reference in the session. The selected model estimates are not the revealed reference. The unmodified capture SHA-256 is `c575895f647c7c2a9548df175767f7f2e7d0dc6080a7dac13175e4e3c9d5dde4`; session and native-interaction checks are kept with the redesign evidence. Quantitative result plots are generated by `materialmind.benchmark.plot_results` directly from experiment outputs rather than redrawn as promotional graphics.
