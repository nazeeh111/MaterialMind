# Visual source assets

`brand.svg` is the original 1280×640 social preview. The geometric cell is a symbolic brand mark, explicitly labelled as illustrative. `architecture.svg` documents software boundaries. `workflow.svg` documents scientific data flow, partitioning, calibration, acquisition, reference reveals and evaluation. Every SVG retains editable text and geometry; matching PNGs provide convenient previews.

`lab.png` and `lab-revealed.png`, when present, are authentic current-source application screenshots. Their creation and use are recorded in the launch film's provenance and verification files. Quantitative result plots are generated by `materialmind.benchmark.plot_results` directly from experiment outputs rather than redrawn as promotional graphics.
