# A real catalog structure

`catalog-crystal.cif` is the unrelaxed WBM initial structure **wbm-1-48468**, NdRu.
It is included in the test catalog and attributed under CC BY 4.0 in DATA_LICENSE.md.
Import this file into the lab to check geometry and recover its cached model estimate.
No reference label is included in this example.

`reference-replay.json` is an authentic UI export after one deterministic top-ranked reference reveal. It retains preselection model outputs, acquisition weights, the revealed archived DFT label, the model revision and complete measured benchmark summary. It is a demonstration record, not a new independent experiment.
